# Memory Assistant - Android + Python

This project contains:
- Kotlin Android application
- XML layouts, values and values-night resources
- AndroidManifest.xml and network security configuration
- Room local memory database
- Retrofit communication with Python
- Modular FastAPI Python backend
- Persistent JSON memory store
- API health endpoint and tests

## Android
Open the root folder in Android Studio and run the `app` configuration.

For the Android Emulator, the backend base URL is:
`http://10.0.2.2:8000/`

## Python
See `backend/README.md`.
